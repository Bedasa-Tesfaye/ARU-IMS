Place hero video files here to appear on the landing page.

Filenames (recommended):
- hero-1.mp4
- hero-2.mp4
- hero-3.mp4

Supported formats: MP4 (H.264) and WebM. Keep files reasonably small (~2-10 MB) for fast loading. The landing page will automatically rotate between the videos every 8 seconds in dev and production.

If you prefer different names, update `resources/js/Pages/LandingPage.jsx` and set `heroVideos` to point to your file paths.
